# Oboth Richard — Personal Portfolio

A clean, responsive, assessment-ready personal portfolio website built with vanilla HTML, CSS and JavaScript.

## Folder structure

- `index.html` — main website
- `style.css` — complete styling and responsive layout
- `script.js` — mobile navigation, reveal animations and dynamic year
- `assets/` — place your personal images/files here

## Before publishing

1. Replace the `OR` profile placeholder in `index.html` with your own photo if desired.
2. Change `your.email@example.com` to your real email address.
3. Replace the LinkedIn and GitHub placeholder links with your real profiles.
4. Review the education/project wording and adjust anything you want to present differently.
5. Open `index.html` in a browser to test it.

## Publishing

This is a static website, so it can be published on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any normal web host.

No database or server is required.

## Assessment features

- Semantic HTML5 structure
- Responsive mobile/tablet/desktop design
- Professional navigation
- Animated section reveals
- Skills and project cards
- Education/experience timeline
- Contact section
- Accessible navigation labels
- SEO description and author metadata
- No external JavaScript frameworks required
